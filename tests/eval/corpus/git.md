# Git

Git is a free and open-source distributed version control system created by
Linus Torvalds in 2005 to manage the development of the Linux kernel. Each
working copy of a Git repository is a full clone, including the complete
history, which means most operations can be performed locally without a
network connection.

Common Git commands include `git clone` (copy a repository), `git status`
(show pending changes), `git commit` (record a snapshot of the staging
area), and `git push` (publish local commits to a remote). Branches in Git
are lightweight movable pointers to commits, making feature branching very
cheap compared to centralized version control systems.

GitHub, GitLab, and Bitbucket are popular hosting services built on top of
Git that add issue tracking, pull/merge requests, and CI/CD integrations.
