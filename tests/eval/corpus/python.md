# Python language

Python is a high-level, general-purpose programming language created by
Guido van Rossum and first released in 1991. It emphasizes code readability
through significant indentation rather than curly braces.

Python supports multiple programming paradigms, including procedural,
object-oriented, and functional programming. It is dynamically typed and
garbage-collected, with a comprehensive standard library often described
as "batteries included."

The reference implementation is CPython, written in C. PyPy is an
alternative implementation that uses a just-in-time compiler to deliver
faster execution for many workloads. As of the 3.x line, Python 2 has been
end-of-life since January 2020 and is no longer maintained.
